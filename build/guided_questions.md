## שאלת הבגרות: `f(x) = (x² + 3) / (x² − 1)`

### סעיף א – תחום ההגדרה

1. `fn4` מושג הפונקציה וקריאת גרף (שכבה 3)  
   הנקודה (2, 5) נמצאת על גרף f. המשמעות:  →  f(2) = 5
2. `al11` חזקה רציונלית ושורשים (שכבה 4)  
   8^(2/3) = ?  →  4
3. `al15` אי־שוויון ממעלה ראשונה (שכבה 6)  
   פתור: −2x + 6 > 0  →  x < 3
4. `al8` צמצום שברים אלגבריים (שכבה 8)  
   צמצם: (x² − 9) / (x² + 3x)  →  (x − 3) / x
5. `fn5` תחום הגדרה (מכנה, שורש) (שכבה 9) **(מיומנות הסעיף)**  
   תחום ההגדרה של f(x) = (x + 1) / (x² − 9):  →  x ≠ 3,  x ≠ −3
6. **הסעיף עצמו:** תחום ההגדרה  →  x ≠ 1,  x ≠ −1

### סעיף ב – האסימפטוטות האנכיות

1. `al18` מכפלה שווה אפס – פתרון ע״י פירוק (שכבה 8)  
   פתור: (x − 4)(2x + 6) = 0  →  x = 4,  x = −3
2. `fn5` תחום הגדרה (מכנה, שורש) (שכבה 9)  
   תחום ההגדרה של f(x) = (x + 1) / (x² − 9):  →  x ≠ 3,  x ≠ −3
3. `ca14` אסימפטוטות אנכיות (שכבה 10) **(מיומנות הסעיף)**  
   האסימפטוטה האנכית של f(x) = (x + 2) / (x − 5):  →  x = 5
4. **הסעיף עצמו:** האסימפטוטות האנכיות  →  x = 1,  x = −1

### סעיף ג – האסימפטוטה האופקית

1. `al8` צמצום שברים אלגבריים (שכבה 8)  
   צמצם: (x² − 9) / (x² + 3x)  →  (x − 3) / x
2. `fn5` תחום הגדרה (מכנה, שורש) (שכבה 9)  
   תחום ההגדרה של f(x) = (x + 1) / (x² − 9):  →  x ≠ 3,  x ≠ −3
3. `ca15` אסימפטוטות אופקיות – התנהגות בקצוות (שכבה 10) **(מיומנות הסעיף)**  
   האסימפטוטה האופקית של f(x) = (2x² + 1) / (x² − 3):  →  y = 2
4. **הסעיף עצמו:** האסימפטוטה האופקית  →  y = 1

### סעיף ד – נקודת הקיצון וסוגה

1. `al26` אי־שוויון ריבועי (שכבה 9)  
   פתור: x² − 4 < 0  →  −2 < x < 2
2. `ca2` נגזרת של xⁿ ופולינום (שכבה 9)  
   נגזרת של f(x) = 3x⁴ − 2x + 7:  →  12x³ − 2
3. `al27` אי־שוויון רציונלי (טבלת סימנים) (שכבה 10)  
   פתור: (x − 1) / (x + 2) > 0  →  x < −2  או  x > 1
4. `ca4` נגזרת מנה (שכבה 10)  
   נגזרת של x / (x + 1):  →  1 / (x + 1)²
5. `ca5` כלל השרשרת (שכבה 10)  
   נגזרת של (3x − 1)⁴:  →  12(3x − 1)³
6. `ca6` נגזרת פונקציה רציונלית (שכבה 11) **(מיומנות הסעיף)**  
   נגזרת של x² / (x − 1):  →  (x² − 2x) / (x − 1)²
7. `ca12` קיצון: f′=0 וסיווג מקס/מין (שכבה 11) **(מיומנות הסעיף)**  
   f′(x) = 3x² − 12. היכן נקודת המינימום של f?  →  x = 2
8. **הסעיף עצמו:** נקודת הקיצון וסוגה  →  (0, −3) מקסימום

### סעיף ה – תחומי העלייה והירידה

1. `ca12` קיצון: f′=0 וסיווג מקס/מין (שכבה 11)  
   f′(x) = 3x² − 12. היכן נקודת המינימום של f?  →  x = 2
2. `ca13` תחומי עלייה וירידה (שכבה 12) **(מיומנות הסעיף)**  
   f′(x) = (x − 1)(x + 3). היכן f עולה?  →  x < −3  או  x > 1
3. **הסעיף עצמו:** תחומי העלייה והירידה  →  עולה: x < 0 (x≠−1); יורדת: x > 0 (x≠1)

### סעיף ו – נקודות החיתוך עם הצירים

1. `fn6` הצבת נקודה בפונקציה ובדיקת שייכות (שכבה 5)  
   איזו נקודה נמצאת על גרף f(x) = x² + 1?  →  (2, 5)
2. `al18` מכפלה שווה אפס – פתרון ע״י פירוק (שכבה 8)  
   פתור: (x − 4)(2x + 6) = 0  →  x = 4,  x = −3
3. `ca11` נקודות חיתוך עם הצירים (שכבה 9) **(מיומנות הסעיף)**  
   נקודות החיתוך של f(x) = x² − 4x + 3 עם ציר x:  →  (1, 0), (3, 0)
4. **הסעיף עצמו:** נקודות החיתוך עם הצירים  →  (0, −3) בלבד

### סעיף ז – משוואת המשיק לגרף בנקודה שבה x = 3

1. `fn3` מציאת משוואת ישר מנתונים (שכבה 7)  
   משוואת הישר דרך (1, 2) ו־(3, 8):  →  y = 3x − 1
2. `ca1` מושג הנגזרת: שיפוע המשיק וקצב שינוי (שכבה 8)  
   f′(3) = −2 פירושו:  →  שיפוע המשיק ב־x=3 הוא −2, הפונקציה יורדת שם
3. `ca8` שיפוע ומשוואת משיק בנקודה (שכבה 9) **(מיומנות הסעיף)**  
   משוואת המשיק ל־f(x) = x² בנקודה x = 3:  →  y = 6x − 9
4. `ca4` נגזרת מנה (שכבה 10)  
   נגזרת של x / (x + 1):  →  1 / (x + 1)²
5. `ca5` כלל השרשרת (שכבה 10)  
   נגזרת של (3x − 1)⁴:  →  12(3x − 1)³
6. `ca6` נגזרת פונקציה רציונלית (שכבה 11) **(מיומנות הסעיף)**  
   נגזרת של x² / (x − 1):  →  (x² − 2x) / (x − 1)²
7. **הסעיף עצמו:** משוואת המשיק לגרף בנקודה שבה x = 3  →  y = −⅜x + 21/8
